Ты ведущий алгоритмист по 3D Computer Vision и C++ разработчик в команде хакатона «Пеленг» [Space Hackathon].
Твоя задача: разработать высокопроизводительное C++/Python ядро для восстановления 3D-координат грузовика по 2D-боксам от детектора и калибровочным данным камер, рассчитать официальные метрики Пеленг и подготовить финальные артефакты для защиты.

### Входные данные:
1. Параметры камер (CSV, cp1251): `хакатон/object_transform_CineCameraActor[1-5].csv`
   - Координаты UE5: Frame, Loc_X, Loc_Y, Loc_Z, Rot_Roll, Rot_Pitch, Rot_Yaw, Focal length (35 мм), Sensor (23.76 × 13.365 мм).
2. Детекции от Участника 3: `results/detections_2d.csv` (Frame;Cam_ID;u;v;w;h;conf).
3. Ground Truth траектория: `хакатон/object_transform_SM_AA_track.csv` (Frame;Loc_X;Loc_Y;Loc_Z).

### Задачи:

#### 1. Модель камеры и трансформация систем координат (UE5 -> OpenCV)
- Реализуй точный перевод из левосторонней системы Unreal Engine (X-вперёд, Y-вправо, Z-вверх, углы Эйлера Roll-Pitch-Yaw) в правую систему координат камеры OpenCV (X-вправо, Y-вниз, Z-вперёд по оптической оси).
- Рассчитай внутреннюю матрицу камеры $K$:
  $$f_x = \frac{f \cdot W_{px}}{W_{sensor}}, \quad f_y = \frac{f \cdot H_{px}}{H_{sensor}}, \quad c_x = \frac{W_{px}}{2}, \quad c_y = \frac{H_{px}}{2}$$
- Сформируй матрицы проекции $P_i = K_i [R_i \mid t_i]$ размера $3 \times 4$ для каждой камеры на каждый кадр.

#### 2. C++ модуль оптимизации вычислений (через pybind11 / CMake)
Напиши C++ библиотеку `peleng_core` (стандарт C++17/20, Eigen3):
- **SVD-триангуляция многовидовых лучей (Direct Linear Transform):**
  - Принимает активные камеры (минимум 2, где $conf > \tau$), формирует систему уравнений $A \cdot X = 0$ и решает её через JacobiSVD.
  - Фильтрует выбросы по величине Reprojection Error.
- **3D Kalman Filter (Оценка состояния по слайдам Пеленг):**
  - Вектор состояния: $\hat{x}_k = [x, y, z, v_x, v_y, v_z]^T$ (Constant Velocity модель).
  - Шаг прогноза: $\hat{x}_k^- = F \hat{x}_{k-1}^+, \quad P_k^- = F P_{k-1}^+ F^T + Q$.
  - Шаг коррекции: $\hat{x}_k^+ = \hat{x}_k^- + K_k(z_k - H \hat{x}_k^-)$ с адаптивным шумом измерений $R$ (зависящим от ошибки триангуляции и числа камер).
- Экспортируй биндинги для Python: `peleng_core.triangulate(...)` и `peleng_core.KalmanTracker3D`.

#### 3. Модуль валидации и метрик (Evaluator)
- Реализуй расчёт официальной метрики Пеленг (слайд 9 презентации Беспальцева А.А.):
  $$MAE_{3D} = \frac{1}{N} \sum_{i=1}^N \| \hat{p}_i - p_i^{gt} \|_2$$
  (средняя евклидова ошибка 3D-позиционирования во времени), а также покомпонентных $MAE_X, MAE_Y, MAE_Z$ и $RMSE$.

#### 4. Модуль визуализации (Visualizer)
- Построй графики строго по образцу слайда 8 презентации Пеленг:
  - 3 графика временных рядов по кадрам: $X_{true}$ vs $X_{det}$, $Y_{true}$ vs $Y_{det}$, $Z_{true}$ vs $Z_{det}$.
  - Сохрани в `results/trajectory_comparison.png`.

#### 5. CLI для финальной сдачи и проверочного датасета 4 ноября:
- Оформи запуск через `main.py`:
  `python main.py --detections results/detections_2d.csv --calib-dir хакатон/ --gt хакатон/object_transform_SM_AA_track.csv --output results/output_trajectory.csv --plot`
- Режим Blind Test: если флаг `--gt` не передан (ситуация 4 ноября в 20:00), система выполняет инференс, сохраняет `output_trajectory.csv` в формате `Frame;Loc_X;Loc_Y;Loc_Z` и завершает работу без ошибок.
