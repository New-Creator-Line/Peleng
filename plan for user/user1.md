Ты работаешь в роли Data Engineer в команде хакатона «Пеленг» [Space Hackathon].
Твоя задача: создать качественный, аугментированный и защищенный от утечек датасет для обучения детектора грузовика на основе 5 видеофайлов в соответствии с документом `dataset_preparation_plan.md` и слайдами 4-5 презентации Пеленг.

### Входные данные:
- Видео: `хакатон/Way1.FinalImage.CineCameraActor[1-5].mp4` (5 синхронизированных ракурсов).

### Задачи:
1. **Нарезка кадров (Frame Extraction):**
   - Напиши скрипт `extract_frames.py` (OpenCV / ffmpeg).
   - Шаг нарезки: 1–3 FPS (НЕ нарезать все 30 FPS, чтобы избежать дублирования и оверфиттинга).
   - Нейминг: `cam{cam_id}_f{frame_idx:05d}.jpg`.
   - Добавь 5–10% пустых фоновых кадров (сцены гор/ландшафта без грузовика) для обучения модели подавлению False Positives (слайд 5).

2. **Черновая разметка (Semi-Automated Pre-labeling):**
   - Напиши скрипт `auto_label.py`: примени готовую модель (Grounding DINO / SAM 2 / YOLOv8x с классом 7 `truck`) для первичной расстановки bounding box.
   - Формат аннотаций: YOLO `.txt` (`0 x_center y_center width height` в относительных координатах 0.0–1.0).
   - Сохраняй аннотации с идентичными именами картинок.

3. **Разбиение данных БЕЗ утечек (Data Leakage Prevention):**
   - Напиши `split_dataset.py`.
   - Правило: разбиение СТРОГО по камерам или временным интервалам видео (например: Камеры 1, 2, 4, 5 — `train/val`, Камера 3 — `test`). Запрещено рандомно перемешивать соседние кадры!
   - Структура:
     ```text
     dataset/
     ├── dataset.yaml
     ├── images/ {train, val}
     └── labels/ {train, val}
     ```

4. **Пайплайн зашумления и аугментаций (Albumentations):**
   - Напиши модуль `augmentations.py` с классом трансформаций для `train` выборки (валидация остается ЧИСТОЙ):
     - `GaussNoise` / `ISONoise` — симуляция шумов матрицы при низкой освещенности.
     - `MotionBlur` / `GaussianBlur` — смаз быстрого движения грузовика и расфокус оптики.
     - `ImageCompression` (JPEG quality 40-75) — симуляция артефактов сжатия видеопотока MP4/RTSP.
     - `RandomBrightnessContrast` & `HueSaturationValue` — тени и перепады освещения.
     - `CoarseDropout` — симуляция частичных перекрытий объекта.
   - Скрипт `verify_dataset.py`: отрисовка 20 случайных аугментированных кадров с боксами для визуального контроля корректности координат.
