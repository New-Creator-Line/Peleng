# Слайд 2: Наше решение, Датасет и Архитектура

## 1. Новый датасет и специализированный детектор кабины

Вместо попыток угадать смещение от 20-метрового кузова мы разработали таргетированный модуль детекции кабины:

* **Генерация датасета (`scripts/dataset/generate_cabin_dataset.py`):**
  - Из всех 5 синхронизированных видеопотоков нарезано и геометрически размечено **`855 кадров`**.
  - Использована точная 3D-модель кабины ($4.2 \times 3.2 \times 3.6\text{ м}$), спроецированная на плоскость каждого ракурса.
  - Сформирован датасет [`data/cabin_dataset/data.yaml`](file://data/cabin_dataset/data.yaml).
* **Обучение нейросети (`weights/cabin/peleng_cabin_best.pt`):**
  - Легковесная модель с FP16 AMP.
  - **Рекордная 2D-точность:** систематический сдвиг по горизонтали $U$ = **`-0.29 px`**, по вертикали $V$ = **`+1.40 px`**. Средняя погрешность центроида всего $4–7\text{ px}$.

## 3. Математическое ядро и фильтрация

1. **RANSAC-триангуляция $N$ лучей ([`src/cuboid_ukf.py`](file://src/cuboid_ukf.py)):**
   - Робастный поиск точки минимальной пространственной невязки лучей (Skew Ray RMSE).
2. **10D CTRV UKF ([`src/tracker_ukf.py`](file://src/tracker_ukf.py)):**
   - Вектор состояния: координаты $X, Y, Z$, скорости $V_x, V_y, V_z$, курс $\psi$, скорость рыскания $\dot{\psi}$, а также онлайн-оценка габаритов $L, W, H$.
3. **Двунаправленный сглаживатель RTS ([`src/rts_smoother.py`](file://src/rts_smoother.py)):**
   - Устраняет разрывы при входе и выходе автопоезда из слепых зон леса и холмов.

## 4. Мультикамерная реконструкция окружения и 3D WebGL-вьюер

* **4 метода 3D-реконструкции рельефа (`src/terrain/`):**
  1. *Method 1 (Space Carving)*: силуэтная резка вокселей + Marching Cubes.
  2. *Method 2 (Metric Depth Fusion)*: Depth-Anything-V2 Outdoor с привязкой к полотну дороги.
  3. *Method 3 (Epipolar Stereo)*: поиск соответствий вдоль эпиполярных линий по NCC.
  4. *Method 4 (Census Transform Stereo)*: непараметрический Census-трансформ с расстоянием Хэмминга по секторам.
* **Интерактивный Three.js вьюер ([`results/peleng_3d_viewer.html`](file://results/peleng_3d_viewer.html)):**
  - Автономный HTML (21 МБ, без сторонних серверов).
  - Настоящая 3D-модель `CargoTruck.fbx` через Three.js FBXLoader.
  - Возможность вселения в ракурс любой камеры (POV 1..5) по клику и возврат в полет по `Esc`.
  - Динамический селектор моделей для наглядного сравнения поколений.
